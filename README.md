# EDEL_TECH_NEW_WEBSITE

**Project Overview**

EDEL ECH WEBSITE is a modern and responsive corporate website developed for Edel Tech. The website is designed to showcase the company’s services, solutions, industry expertise, case studies, and business capabilities while providing visitors with an easy way to contact the company and book product or service demonstrations.

The project follows a full-stack web development architecture using React.js for the frontend, Node.js and Express.js for the backend, and PostgreSQL for secure and structured data storage.
Technology Stack

**Frontend**

The frontend is developed using React.js to provide a responsive, interactive, and user-friendly interface. It includes reusable components, dynamic page navigation, forms, animations, and industry-specific content.

**Backend**

The backend is developed using Node.js and Express.js. It handles API requests, business logic, form validation, error handling, and communication between the frontend and the PostgreSQL database.

**Database**

PostgreSQL is used as the relational database management system. It stores website data such as demo booking requests, contact-form submissions, chatbot messages, selected dates and time slots, and other business-related information.

**Main Features**

- Modern and responsive corporate website design
- Separate pages for company services and solutions
- Industry-specific pages and content
- SAP and RPA service information
- Contact and enquiry forms
- Demo and meeting booking functionality
- Date and time-slot selection
- Prevention of duplicate meeting-slot bookings
- Chatbot with predefined questions
- Storage of form and chatbot data in PostgreSQL
- Frontend-to-backend API integration
- Form validation and error handling
- Case studies and business success stories
- Search functionality
- Interactive animations and user-interface elements
  
**Project Architecture**

The website follows a three-layer architecture:
1. **Presentation Layer**:
   The React.js frontend displays website content and collects user input.
3. **Application Layer**:
   The Node.js and Express.js backend processes requests, applies validation, and manages application logic.
4. **Data Layer**:
   PostgreSQL securely stores and retrieves website information.
   
**Project Objectives**

The main objectives of this project are:
- To establish a professional online presence for Edel Tech.
- To clearly present the company’s products, services, and expertise.
- To help potential clients explore relevant industry solutions.
- To allow users to submit enquiries and book demonstrations.
- To automate the storage and management of customer requests.
- To provide a scalable foundation for future website enhancements.
- To deliver a secure, responsive, and easy-to-maintain corporate platform.
  
**Conclusion**

EDEL TECH WEBSITE is a full-stack corporate website that combines a responsive React.js frontend with a Node.js and Express.js backend and a PostgreSQL database. It provides a professional digital platform for presenting Edel Tech’s capabilities, engaging potential customers, collecting enquiries, and managing demo bookings efficiently.
